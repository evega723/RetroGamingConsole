API
js file uses method: XMLHttpRequest(); to open the web API, and store it in an array. 
The status is checked with an if statement and if the request is sucsessful, it will use JSON.parse(); 
to make each console a js object, each of which is formatted as a bootstrap card.

Summary
the summary line is calculated as follows:
1. consoleArray.length is used to calculate the total
2. a for loop is used to compare and verify both the oldest and newest consoles against
   the others by comparing their years
